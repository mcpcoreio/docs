## What is MCPCore?

**MCPCore** is a managed platform for the [Model Context Protocol (MCP)](https://modelcontextprotocol.io). It lets you write tool logic in JavaScript, or build it visually without code, and get a live, MCP-compliant endpoint in under 30 seconds, with no Docker, no servers, and no `node_modules`.

MCPCore currently implements MCP specification version **2026-07-28**, the current stable release of the protocol.

You write the code that matters. MCPCore handles everything else:

- **MCP server hosting**, your tools run in an isolated, always-on sandbox
- **AI Tool Builder**, describe what you want in plain language and let AI generate the tool code, parameters, and naming for you
- **Professional code editor**, a VS Code-style editor with syntax highlighting, ready-made snippets, AI-powered completions, and an integrated terminal
- **No-code workflow builder**, connect Database, Query, HTTP Request, Transform, Condition and For Each steps on a canvas, handle errors with retries and error branches, and test every step live
- **Generate workflows with AI**, describe a tool in plain words and get the steps, connections and parameters
- **Import from OpenAPI**, turn the endpoints of an existing API into tools in a few clicks
- **Version history**, save drafts, compare versions side by side and restore any earlier version
- **Playground**, chat with Claude or an OpenAI model using your own key and watch it call your tools
- **One-click client install**, add a server to Cursor, VS Code, Claude Desktop, Claude Code, Codex or Gemini CLI without editing config files
- **Authentication**, choose from 4 security modes (Public, API Key, OAuth 2.0, Bearer Token)
- **Custom domains**, use your own domain with automatic SSL provisioning
- **Encrypted secrets**, store API keys and credentials securely, referenced in code as `env.MY_KEY`
- **Observability**, real-time traffic logs, error traces with AI-assisted debugging, and analytics dashboards with interactive charts, including which AI clients call your server

## How it fits together

The AI model never touches your database or external APIs directly. It calls your MCPCore tool, which runs your sandboxed code and returns a structured result. This separation keeps your infrastructure secure and your integrations composable.

```
AI Client (Claude, Cursor, VS Code, etc.)
      │  MCP protocol
      ▼
MCPCore (hosted MCP server)
      │  your sandboxed code
      ▼
External APIs, Databases, Services
```
